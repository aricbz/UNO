# Standardized game logos

Five wiki-ready PNG assets, each 1024 × 1024 pixels with an embedded sRGB profile and transparent background. Complete artwork fits proportionally within an 896 × 896 area, centered with at least 64 pixels of clear space on each side. Shapes are never stretched to a common aspect ratio.

| UNO Dare Adults Only | uno-dare-adults-only-logo.png |

The classic UNO asset retains the supplied digital artwork, with only its exterior white background removed and its canvas standardized. The other four assets are digitally restored reconstructions from the supplied references, rather than official vector originals or pixel-identical copies. The source files remain in the parent folder.

Intentional logo styling is preserved: FLIP’s lettering, Liar’s distressed stamp, No Mercy’s distressed black panels, and Dare’s white/red neon glow, Adults Only subtitle, divider, and tagline. Dare’s neon halo uses partial transparency; display it on a dark background for the strongest effect. White letters and keylines remain opaque within the other logos.

Use the full square PNG canvas consistently in wiki layouts with proportional image sizing. Transparency allows the page background to show through.
