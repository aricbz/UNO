# Official UNO Rules

Original Mattel instruction PDFs, checked November 3, 2026. Downloaded files are byte-for-byte identical to the source PDFs; no pages have been cropped, rewritten, merged, or recompressed.

## Naming

`<game-or-pack>-rules-en.pdf` uses lowercase hyphenated names consistent with the card assets. `en` means the PDF includes English instructions; several original publisher files also contain other languages, folding diagrams, or production layouts. Those have been preserved.

## Verification notes

All ten files open in PDFKit with the page counts above. Titles and game-specific content were checked against Mattel support listings and the rendered sheets. Liar's UNO is an image-based PDF; its English panel was verified visually. UNO FLIP is the double-sided Light Side/Dark Side card game. The No Mercy expansion includes the 24 cards and 6 coins. Mattel's source filename for No Mercy uses `HVW18`, while the support product code is `HWV18`.

The base-game PDF is the classic 108-card UNO instruction sheet. Its English rules appear alongside other original publisher language/production pages.

## UNO Dare Adults Only: accepted substitute

At the user's request, the original Mattel **standard UNO Dare (CDY11)** instructions are included as the accepted substitute for **UNO Dare Adults Only (HRL30)**. The filename remains `uno-dare-rules-en.pdf` to identify the actual edition accurately.

This is the standard game's rule sheet, not the Adults Only leaflet; it does not document the Adults Only dare die or its four dare levels. The original PDF is preserved unchanged. All requested entries are now covered, with this substitution.
